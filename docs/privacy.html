PageDrone Privacy Policy

Last updated: 2026-08-24 · Contact: see GitHub repository

Overview

PageDrone is a Chrome MV3 extension that automates repetitive web tasks on sites you explicitly configure. All settings, skills, flows and logs are stored locally in chrome.storage on your device. We do not operate a backend that collects your data.

Data We Do Not Collect

  • No passwords, cookies or browsing history are uploaded to any server.
  • No remote code is executed. User-provided "custom script" steps run only the code you paste locally.
  • We do not sell or share data with third parties.

Permissions & Why They Are Needed

  • storage / unlimitedStorage — save your sites, skills, flows and logs locally.
  • alarms — schedule daily runs.
  • scripting — inject local automation functions into tabs you configured.
  • tabs — create/focus/close tabs for automation runs.
  • cookies — read local cf_clearance to detect challenge-page clearance; not uploaded.
  • notifications — notify you of run results or human-intervention needed.
  • host_permissions <all_urls> — you may configure any https site as a target; the extension only accesses sites you saved.

Contact

Open an issue on GitHub or contact the publisher email listed on the Chrome Web Store listing.
