如何填写步骤？点开查看

扩展会按顺序操作网页。最常见只需 2 步：

  1. 点击元素 — 填签到按钮的选择器（CSS 或 XPath）
  2. 等待文字出现 — 附加栏填「签到成功」等提示语

复制选择器：网页按 F12 → 选中按钮 → 右键 HTML → Copy → Copy selector 或 Copy XPath，粘贴到「目标」框。

支持 CSS（如 .checkin）和 XPath（如 //button[contains(.,"签到")]）。

脚本内容

需 return { ok, message }，支持 async/await。无法使用 chrome.* API。
